# Janith Ramanayake - Portfolio

This is a Next.js portfolio website showcasing research, publications, projects, and blog posts.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Building for Production

To build the static site for GitHub Pages:

```bash
npm run build
```

This will generate a static export in the `out` directory.

## Deployment to GitHub Pages

The site deploys automatically via GitHub Actions — just push to `main`.
See [DEPLOYMENT.md](DEPLOYMENT.md) for the one-time setup (repo naming +
enabling Pages).

## Project Structure

- `/app` - Next.js app router pages
- `/components` - React components
- `/public` - Static assets (images, etc.)

## Features

- Fully responsive design
- TypeScript support
- Tailwind CSS styling
- Static site generation for GitHub Pages
- Blog with dynamic routes
- Smooth scrolling navigation
- Mobile-friendly menu

## Technologies Used

- Next.js 16
